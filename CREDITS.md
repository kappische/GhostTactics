# Credits

## Inspiration

Ghost Tactics is inspired by **Horror Tactics** (2009) by [Oxeye Game Studio](http://www.oxeyegames.com/).

Horror Tactics was a free tactical squad game prototype, itself inspired by the *Space Hulk* board game. The core gameplay concept — moving a squad through tight corridors while keeping backs covered against unseen enemies — originates from that work.

All code in this repository is an independent reimplementation in JavaScript/Phaser.js.

## Music

Music tracks carried over from the original Horror Tactics prototype. If you are the original composer and would like credit or removal, please open an issue.

## Libraries
